## 📖 What is Vibe Agency? (In Simple Terms)

Instead of working with just one single AI assistant, **Vibe Agency** gives you an entire **company of AI agents** working together as a coordinated team:

* 🕵️ **Researcher Agent:** Scrapes data, searches the web, and monitors competitors.
* ✍️ **Copywriter Agent:** Writes marketing copy, product descriptions, and email drafts.
* 💻 **Developer Agent:** Writes code, fixes bugs, and builds features.
* 🧪 **QA Tester Agent:** Reviews the code and verifies everything works before shipping.
* 📋 **Project Manager Agent:** Keeps all agents on track and reports progress to you.

## 💬 Real-World Prompts: What You Type ➔ What You Achieve

Here is how anyone can deploy autonomous AI agent teams using simple chat prompts:

---

### 1. 👥 Deploy a Coordinated Multi-Agent Team
> **What it does:** Launches multiple specialized agents that collaborate to complete complex tasks.

* **💬 What you type in chat:**
  ```text
  "Deploy a 3-agent team: Agent 1 researches competitor prices, Agent 2 writes a comparison report, and Agent 3 sends me an email summary."
  ```
* **🎯 What you achieve instantly:**
  * Spawns 3 specialized sub-agents with dedicated roles, passing data seamlessly between each other until the mission is 100% complete.

---

### 2. ⏰ Overnight Heartbeat Cron & Scheduled Automation
> **What it does:** Runs automated agent workflows overnight while you sleep.

* **💬 What you type in chat:**
  ```text
  "Run an overnight market check every morning at 3:00 AM ACST, scrape stock levels, and alert me if popular laptops are low on stock."
  ```
* **🎯 What you achieve instantly:**
  * Schedules a persistent background heartbeat cron that awakens the agent team every morning to execute the task autonomously.

---

### 3. 📬 Inter-Agent Message Inboxes & Task Delegation
> **What it does:** Allows one agent to hand off work to another agent automatically.

* **💬 What you type in chat:**
  ```text
  "Have the Developer Agent write the shipping calculation code, and automatically hand it off to the QA Agent to test for errors before approving."
  ```
* **🎯 What you achieve instantly:**
  * The Developer agent commits code and sends a direct message to the QA agent's inbox for review and automated verification.

---

### 4. 📝 Define Custom Agent Personas in Markdown
> **What it does:** Creates new agent team members with specific job descriptions and rules.

* **💬 What you type in chat:**
  ```text
  "Create a 'Senior SEO Copywriter' agent specializing in Australian electronics and e-commerce buyer guides."
  ```
* **🎯 What you achieve instantly:**
  * Generates a clean `roles/seo-copywriter.md` definition file with customized system instructions and tool access.

---

### 5. 🌐 Live Web Console & Team Visualizer
> **What it does:** Provides a live browser dashboard to monitor your agent team in real-time.

* **💬 What you type in chat:**
  ```text
  "Open the Vibe Agency web console to monitor active agent tasks and live message exchanges."
  ```
* **🎯 What you achieve instantly:**
  * Launches the interactive dashboard ([Live Demo](https://shahrukh-hack.github.io/vibe-agency/)) displaying real-time agent status, inbox logs, and execution graphs.

---

## ⚡ 60-Second Quickstart

```bash
# 1. Initialize your agency workspace
npx vibe-agency init

# 2. Launch the team orchestrator
npx vibe-agency run --team "Market-Researcher,Copywriter,QA"

# 3. Start the live Web Console
npx vibe-agency console
```
